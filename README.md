# incrementale-godot

Reconstruction de [Incrementable](https://github.com/juanrobin09-stack/Incrementable) (jeu incremental/idle où le joueur incarne une force de la nature qui déclenche des catastrophes sur un village) sur le moteur **Godot 4.x**.

Reconstruction indépendante, pas un portage automatique : le rendu canvas, le HUD CSS et la logique JS de l'original ne se copient pas tels quels dans Godot — chaque couche est réécrite dans son propre paradigme (nœuds/scènes, `Control`/thèmes, GDScript).

  Trois défauts remontés après un premier test en jeu, tous corrigés dans la foulée : (1) *trous visibles pendant la transition* — l'intacte et l'endommagée sont deux dessins indépendants, pas juste de ratio différent ; les recopier l'une sur l'autre cellule par cellule pouvait coller un fragment endommagé plus transparent exactement là où l'intacte était pleine (bord de toiture typiquement), créant un trou qui n'existe dans aucune des deux images sources — corrigé en remplaçant la recopie franche par une composition alpha (`Image.blend_rect` : ne peut mathématiquement jamais rendre un pixel plus transparent qu'il ne l'était, donc plus jamais de trou).
